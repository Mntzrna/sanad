GTA V on Sanad
1) Open Steam, sign in, install Grand Theft Auto V (about 120 GB).
2) Game properties > Compatibility > Force Proton-GE (install it from ProtonUp-Qt) or latest Proton.
3) Launch options:  gamemoderun mangohud %command%

Notes:
- GTA Online is not supported on Linux (BattlEye). Single player only.
- Needs a real GPU. Inside a VM without GPU passthrough, FPS will be unusable.
